THE CHALLENGE

A high driving position can hide what is close beside a heavy vehicle.

DRISHTI demonstrates how computer vision can make road users visible in a video feed and bring attention to selected regions around the vehicle.

THE DESKTOP PROTOTYPE

A practical demonstration, built to run on an ordinary PC.

01

Road-user detection

YOLOv8n identifies people, bicycles, motorcycles, cars, buses and trucks in a live or recorded feed.

02

Persistent tracking

ByteTrack associates detections across processed frames to distinguish new entries from continued presence.

03

Editable zones

Adjust left and right polygons and observe when an object’s image-space centre enters a selected region.

04

Two-stage display

Advisory and critical colors demonstrate how simulated turn indicators can affect warning priority.

05

Event review

SQLite history, incident snapshots, analytics and CSV export support review after a demo session.

06

Local processing

Video and inference run locally. A computer-speaker alert and optional speech need no added hardware.

WARNING LOGIC

Two visual states. One clear example.

STAGE 1 · ADVISORY

Road user in a zone

A road user enters an enabled image-space region. The dashboard marks the object and records the entry.

STAGE 2 · SIMULATED PRIORITY

Indicator matches the zone

In the desktop simulation, a matching turn-indicator input raises the visual warning priority and can play the critical tone.

The speed and indicator inputs are demonstrations, not readings from a vehicle. These behaviors are not calibrated or certified for road use.

Download the Windows project ZIP, extract it, then follow the short setup below. The desktop app runs on your computer; the landing page itself is only a website.

Download project ZIP ↓ Read setup guide

Run it on Windows · Python 3.10–3.12 required

  1. Extract the ZIP and open the extracted project folder.
  2. Open PowerShell in that folder and create the environment:
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --demo

YOLOv8n weights download on first launch, so internet is needed for setup. Use a webcam or the bundled demo video. This is an educational prototype, not a certified driving-safety system.

run.bat --demo
